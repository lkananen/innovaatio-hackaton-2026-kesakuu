## How the day works

This is a **hands-on**, team event. The theme is **agentic data platform development** —
you use an AI coding agent (examples shown in **VS Code + GitHub Copilot**, but any
agentic tool works) to go from an idea to a **running, demoable implementation**.

Each team picks **one** of three **fully independent** hackathons below and runs it end to
end. Every hackathon is built as an **artifact chain**: each challenge produces a named
file that the next challenge consumes — so a team that stops early still has something to
demo.

:::note[Bring your own data]
Bring a **non-sensitive / public / synthetic** dataset from your own world. No data? Each
hackathon's **Setup** page lists **three ready-to-use open datasets** suited to that track.
:::

:::caution[Do the pre-work]
The **#1 thing that derails the day is Azure readiness** — especially **zero Azure OpenAI
quota** on fresh subscriptions (approval takes 1–3 business days). Each hackathon has a
**Setup & pre-work** page with a checklist to complete **7 days before** the event.
:::
